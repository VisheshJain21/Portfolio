# Vishesh Jain — Portfolio

Personal portfolio of **Vishesh Jain, AI-Native Engineer**. Concept: **"Systems that think"** — a dark, precise, editorial site whose cursor-reactive agentic-graph hero demonstrates the discipline it describes.

## Run it

```bash
npm install
npm run dev        # → http://localhost:3000
```

## Where things live (plain-language map)

| Path | What's in it |
|---|---|
| `src/app/` | Routes & page assembly only |
| `src/components/ui/` | Reusable primitives (Magnetic, Cursor, Preloader…) |
| `src/components/layout/` | Nav, Footer, smooth-scroll provider |
| `src/components/sections/` | The page sections (Hero, Work, Contact…) |
| `src/webgl/` | The hero graph animation (isolated) |
| `src/hooks/` | Reusable React hooks |
| `src/animations/` | Shared GSAP reveal helpers |
| `src/content/` | **All copy & project data — edit content here, not in components** |
| `src/styles/` | Design tokens + global styles |
| `docs/` | Planning: reference analysis & direction board |
